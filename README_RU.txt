ТРТ — МОБИЛЬНОЕ ПРИЛОЖЕНИЕ V1.5

ЧТО ИСПРАВЛЕНО
1. В карточке каждой ТРТ появилась кнопка «Показать продажи» и вкладка «Продажи».
2. Показываются месячные продажи 2025/2026, итог за одинаковый период и динамика в процентах.
3. В списке точек появился фильтр «С продажами» и итог 2026 в карточке точки.
4. Добавлено восстановление резервной копии — пригодится при переносе на другой адрес.
5. Приложение стало переносимым: работает в корне сайта и в подпапке GitHub Pages.
6. Если библиотека карты временно не загрузилась, продажи, точки, визиты и задачи всё равно работают.

ВАЖНО ПРО ПРОДАЖИ
JSON должен быть выгружен из компьютерной версии ПОСЛЕ загрузки координат и файла продаж.
После обновления приложения повторно импортируйте свежий файл:
ТРТ_для_мобильного_приложения_ГГГГ-ММ-ДД.json

ПЕРЕНОС С CLOUDFLARE НА GITHUB PAGES
1. Распакуйте ZIP.
2. Создайте на GitHub новый репозиторий, например trt-mobile.
3. Загрузите в корень репозитория все распакованные файлы и папку icons.
4. Откройте Settings → Pages.
5. Source: Deploy from a branch; Branch: main; Folder: /(root); Save.
6. Откройте выданный адрес вида https://ИМЯ.github.io/trt-mobile/
7. В Chrome установите приложение заново с нового адреса.

ПЕРЕНОС ДАННЫХ
До удаления старой версии: Настройки → Скачать резервную копию.
В новой версии: Настройки → Восстановить резервную копию.
Фото и видео резервная копия пока не переносит.
