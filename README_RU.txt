ТРТ — мобильный помощник v1.7

Что добавлено
- Серверный вход через Yandex API Gateway.
- Проверка действующей сессии при запуске.
- Выход с отзывом сессии на сервере.
- Сохранение авторизации на устройстве.
- Ограниченный офлайн-вход после ранее подтверждённой сессии.
- API-ответы и токены не кешируются Service Worker.

Установка на GitHub Pages
1. Удалите старые файлы в корне репозитория trt-mobile.
2. Загрузите все файлы из этого архива в корень репозитория.
3. Дождитесь обновления GitHub Pages.
4. На телефоне полностью закройте PWA и откройте заново. При необходимости удалите старую установленную версию и установите повторно.

Важно
- Первый вход требует интернет.
- Данные ТРТ, визиты, задачи и медиа в этой версии по-прежнему хранятся локально на устройстве.
- Следующий этап — серверная синхронизация данных.
